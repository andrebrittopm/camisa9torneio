# Visual Changelog — ETAPA 11.1

## Responsividade
- **HeroSection**: Ajustado `line-height` do subtítulo para `md:leading-[0.85]` e tamanho de fonte para melhor equilíbrio em telas mobile (360px).
- **CustomerDataForm**: Padding lateral alterado de `p-10` fixo para `p-6 md:p-10`, melhorando a área útil em dispositivos pequenos.
- **OrderView**: Aumentado contraste das mensagens de rodapé (`text-slate-500` -> `text-slate-400`).

## Consistência de Texto
- Unificação global do termo "Camisa Oficial" em todos os componentes públicos.
- Padronização de botões de ação ("Enviar Comprovante", "Confirmar Pedido").

## Lógica de Navegação
- Âncora de catálogo renomeada de `#camisas` para `#camisa`.
